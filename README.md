# Contact Card Component

---

## Project Description

This project is a scalable, interactive Contact Card component built using React. It serves as the foundational individual activity for our web development series.

**Distinct Feature Highlight:** Implemented quick-action contact buttons including direct email links, direct call triggers, and dynamic `.vcf` (vCard) file generation for saving contact information directly to a device.

---

## Features

* Displays profile picture, name, email, and phone number
* Quick-action buttons:
  * **Email Me**: Opens your default email app
  * **Call Me**: Dials the phone number
  * **Save Contact**: Generates and downloads a `.vcf` contact file

---

## Scalability Note

The component structure was designed with modularity in mind, allowing this to be easily adapted and scaled into larger applications or directory systems.
